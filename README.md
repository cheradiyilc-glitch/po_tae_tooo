### Project Description
**po-tae-too...** is a completely useless, NASA-level bio-tuber diagnostic web application. It scans ordinary potatoes using browser-side computer vision heuristics to determine their existential dread, social battery, and burnout levels — culminating in an authentic, sarcastic Kerala-style Malayalam verdict.

### The Problem (that nobody had)
Human emotions are complicated. Potatoes are easier. In an era where AI is solving grand challenges, nobody stopped to ask: *“How is that potato in your fridge emotionally coping with Monday morning?”* We built an over-engineered diagnostic platform to solve this completely unnecessary question.

### The Solution (that nobody asked for)
1. Drop or snap a potato photo using the live camera scanner.
2. A dramatic 3.8-second sci-fi laser scan judges the tuber's bumps, curvature, and color temperature.
3. Decodes 12 emotional states (*Existential Sadness, Deadline Anxiety, Suppressed Rage, Unreasonably Confident, Professionally Sleepy, etc.*).
4. Generates a **Potato vs. Human** psychological burnout comparison.
5. Delivers a natural Kerala college-student Malayalam/Manglish punchline verdict.
6. Features a 4-question trauma compatibility quiz, potato roasts, a persistent leaderboard, and a downloadable share card.

## Technical Details

### Technologies / Components Used

#### For Software:
- **Framework**: React 18 + TypeScript
- **Bundler & Tooling**: Vite 6
- **Styling**: Tailwind CSS (minimalist dark zinc palette with warm potato amber accents)
- **Animations**: Framer Motion & Canvas Confetti
- **Audio**: HTML5 Web Audio API (real-time synthesized sci-fi scanning beeps & completion chimes with zero external audio assets)
- **Vision & Intelligence**: Client-side deterministic heuristic engine (canvas pixel sampling, color entropy, texture variation)
- **APIs**: HTML5 `MediaDevices.getUserMedia` (live camera), Web Share API, Clipboard API, `localStorage`
- **Icons**: Lucide React

---

## Key Features

- **100% Offline Local Engine (Zero API Keys)**: Runs entirely in the browser memory using deterministic pixel checksums — no server, no paid vision APIs, and no latency.
- **Dramatic NASA-Grade Scanner**: Sci-fi laser scanning line, HUD reticles, progress counter, and deadpan serious scientific status messages.
- **Authentic Kerala Malayalam Verdicts**: Over 30 natural Manglish & Malayalam punchlines with full text wrapping.
- **Potato vs Human Duel**: Side-by-side animated comparison across Emotional Damage, Social Battery, Overthinking, and Deadline Anxiety.
- **Roast My Potato**: Interactive button with card shake animations and 32+ personalized roasts.
- **Compatibility Quiz**: 4-question relationship diagnostic with score gauge.
- **Hall of Starch Fame**: Add custom potato names (*Bunty, Potato Kumar, Appu Chetta*) to a persistent leaderboard.
- **Downloadable Social Poster**: Client-side HTML Canvas generator exporting clean PNG certificates.
- **1-Click Startup Script**: Double-click `run.bat` on Windows to install dependencies and open the browser automatically.

## Implementation Details

### How the Local Potato Intelligence Engine Works:
```
[Potato Image] 
      ↓
[HTML5 Canvas 100x100 Downsample]
      ↓
[Extract: Average RGB, Luminance, Contrast, Saturation, Texture Variance]
      ↓
[64-Pixel Distributed Checksum Hash (Mulberry32 Seed)]
      ↓
[Dynamic Emotional Mapping across 12 Profiles]
      ↓
[Personalized Malayalam Verdict + Roast + Compatibility Score]
```

## Running Locally

### Option 1: 1-Click Startup (Windows)
Double-click [`run.bat`](./run.bat) in the project root. It will automatically configure the environment, install dependencies, and open your browser at `http://localhost:5173/`.

### Option 2: Manual Terminal Commands
```bash
# 1. Navigate to project folder
cd potato-analyzer

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
